# 南部もぐり観光RPG

岩手県洋野町に伝わる潜水技術「南部もぐり」を題材にした、短時間プレイのゲームアプリです。
南部もぐりを知らない人に疑似体験を通じて関心を持ってもらい、種市歴史民俗資料館などの公式観光情報へ誘導することを目的としています。

## 現在の状況

**ゲームループを再設計している途中です。** リポジトリ内に新旧2つの設計が同居しているため、読む前に次の対応関係を確認してください。

| ディレクトリ | 内容 | 設計 |
|---|---|---|
| `prototype/` | 新ループの検証用プロトタイプ | **新（現行方針）** |

| `backend/` | FastAPI（固定レスポンスの疎通確認まで） | 新旧共通 |
| `docs/` | 要件・画面・API・DB・実装ルール | 旧（改訂待ち） |

設計変更の経緯と、旧設計の扱いは [`docs/design-change-log.md`](docs/design-change-log.md) にまとめています。

## 新しいゲームループ

1. 装備準備タイムアタック（工程を順番にタップ → 残り時間で準備ゲージを連打）
2. 準備ランクの決定（ゲージ到達率で1〜3）
3. 潜水地点の選択（ランクが高いほど遠くへ潜れる）
4. 潜水・宝箱の獲得
5. 仲間が装備を外す演出（豆絞り姿の潜水士が現れる）
6. 結果表示

1プレイ45〜60秒を目標としています。

## プロトタイプの動かし方

`prototype/prep-loop-prototype.html` は依存関係のない単一HTMLです。ブラウザで直接開けます。

スマートフォンで試す場合はローカルサーバー経由で開きます。

```bash
python3 -m http.server 8080
# 同じネットワークの端末から
# http://<PCのIPアドレス>:8080/prototype/prep-loop-prototype.html
```

制限時間・ランク閾値・ポイント量などはファイル冒頭の `CONFIG` にまとめてあります。

## バックエンドの動かし方

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.main:app --reload --port 8001
```

`POST /analyze` はUnityとの疎通確認用で、固定レスポンスを返すだけです。DB保存や推薦判定は未実装です。

## Unity プロジェクト

`unity/NambuQuest`（Unity 6000.5.5f1）を Unity Hub から開きます。
タイトル画面、3ページのチュートリアル、フェード付きシーン遷移、プレイヤーの自由移動、探索地点の接近判定まで実装済みですが、**いずれも旧設計に基づくもの**です。新ループへの作り替えは未着手です。

## 技術構成

- フロント：Unity / C#
- バックエンド：Python / FastAPI
- ORM：PeeWee
- DB：SQLite

## 注意事項

- 装備工程の名称・順番、装備解除を手伝う人数など、プロトタイプ内の文化的な記述は**暫定**です。種市歴史民俗資料館や種市高校への確認前に確定させないでください
- 招待券アイテムは演出とリンク誘導の検証用です。実物特典としての配布条件（発行主体・定員・利用確認など）は未確定です
