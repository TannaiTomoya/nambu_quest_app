# 南部もぐり観光RPG

岩手県洋野町に伝わる潜水技術「南部もぐり」を題材にした、短時間プレイのゲームアプリです。
南部もぐりを知らない人に疑似体験を通じて関心を持ってもらい、種市歴史民俗資料館などの公式観光情報へ誘導することを目的としています。

## 新しいゲームループ

1. 装備準備タイムアタック（3工程を順番にタップ → 残り時間で最終安全確認を連打）
2. 準備ランクの決定（ゲージ到達率で1〜3）
3. 潜水地点の選択（ランクが高いほど遠くへ潜れる）
4. 潜水・宝箱の獲得
5. 仲間が装備を外す演出（豆絞り姿の潜水士が現れる）
6. 結果表示

1プレイ45〜60秒を目標としています。

工程の進行にあわせて2Dキャラクターの装備が「装備なし → 潜水服 → 胸当て・錘 → ヘルメット・送気」と段階的に変化し、連打中はキャラクターが動きます。潜水中は AIR / DEPTH / QUEST のHUDと探索ログを表示し、宝箱は「調べる」→ 調査中 → 開封 の流れで開きます。帰還後の装備解除は動画で再生します。

## プロトタイプの動かし方

`prototype/` は次の2ファイルで構成されています。

- `prep-loop-prototype.html` — 本体（外部ライブラリ非依存）
- `assets/nanbu_return_scene.mp4` — 装備解除・帰還演出の動画（HTMLから相対パスで参照）

動画を含むため、ローカルサーバー経由で開いてください。

```bash
python3 -m http.server 8080
# PC
# http://127.0.0.1:8080/prototype/prep-loop-prototype.html
# 同じネットワークのスマートフォン
# http://<PCのIPアドレス>:8080/prototype/prep-loop-prototype.html
```

制限時間・ランク閾値・ポイント量などはファイル冒頭の `CONFIG` にまとめてあります。招待券・クーポンの内容と地点への割り当ては `TICKETS` と `POINTS_DATA` で定義しています。

## バックエンドの動かし方

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.main:app --reload --port 8001
```

`POST /analyze` はUnityとの疎通確認用で、固定レスポンスを返すだけです。DB保存や推薦判定は未実装です。

## Unity プロジェクト

`unity/NambuQuest`（Unity 6000.5.5f1）を Unity Hub から開きます。
タイトル画面、3ページのチュートリアル、フェード付きシーン遷移、プレイヤーの自由移動、探索地点の接近判定まで実装済みですが、**いずれも旧設計に基づくもの**です。新ループへの作り替えは未着手です。

## 注意事項

- 装備工程の名称・順番、装備解除を手伝う人数など、プロトタイプ内の文化的な記述は**暫定**です。種市歴史民俗資料館や種市高校への確認前に確定させないでください
- 招待券・クーポンは演出とリンク誘導の検証用です。実物特典としての配布条件（発行主体・定員・利用確認など）は未確定で、リンク先運営者への掲載連絡も未実施です
- 帰還演出の動画は生成AI（Kling）で作成した仮素材です
