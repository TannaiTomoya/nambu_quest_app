## 2026-07-30 自由探索型から準備タイムアタック型へ

### 変更前（旧設計）

3〜5分の2D探索型RPG。

- プレイヤーが海底を自由に移動する
- 空気100を消費しながら3つの探索地点を訪れる（消費空気 25 / 40 / 60、安全予備15）
- 持ち帰る記録を最大2件選ぶ
- 帰還後、FastAPI が関心テーマを判定して称号と豆絞り柄を返す

### 変更後（新設計）

45〜60秒の短時間ループ。

1. 装備準備タイムアタック（工程を順番にタップ → 残り時間で準備ゲージを連打）
2. 準備ランクの決定（ゲージ到達率で1〜3）
3. 潜水地点の選択（ランクが高いほど遠くへ潜れる）
4. 潜水・宝箱の獲得
5. 仲間が装備を外す演出（豆絞り姿の潜水士が現れる）
6. 結果表示

### 変更した理由

- イベント会場やWeb体験では1分以内の方が回転率と再挑戦性を両立できる
- 自由移動そのものは題材の理解につながりにくく、操作の習熟コストだけが残る
- 「重い装備は一人では着脱できない」という南部もぐりの特徴を、準備工程と装備解除演出で直接伝えられる

### 表現上の判断

- 準備の評価軸は「錘の数」や「速さ」ではなく**準備の完成度**とする。重い装備をたくさん付けるほど優秀、という誤ったメッセージを避けるため
- 装備解除演出の直前に「この装備は、一人では外せないほど重い。仲間と支え合って、ようやく潜水を終える。」を挟み、素顔の公開を文化紹介と接続する
- 「イケメン」等の容姿への言及は、公式説明・ゲーム内テキスト・称号のいずれにも使わない

## 確認待ちの事項

文化的事実に関わるため、想像で確定してはいけない項目です。

| 項目 | 現状 | 確認先 |
|---|---|---|
| 装備工程の正式名称と順番 | 公開記事から暫定作成（潜水服 → 潜水靴 → シコロ → カップ接続 → 腰ベルト・送気 → 前鉛・後鉛）。記事間で錘の取り付け順に揺れがある | 種市歴史民俗資料館 / 種市高校海洋開発科 |
| 豆絞り柄の妥当性 | ヘルメットの下に手ぬぐいで鉢巻をするのは事実。柄が豆絞りかは未確認 | 同上 |
| 装備解除を手伝う人数と役割 | 実習は3人1組（ダイバー1人 + 介添え2人）。演出は介添え2人に合わせる | 同上 |

## 実装上の凍結事項

- 招待券は演出とリンク誘導の検証のみ。実物特典の運営条件（発行主体・原資・定員・利用確認・失効条件）は未確定
- `POST /analyze` は固定レスポンスのみ。DB保存・推薦ロジックは未実装
- ポイントはゲーム内限定（「もぐりポイント」）。外部価値を持つ地域ポイントや割引券は別フェーズ
