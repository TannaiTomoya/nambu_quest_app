# 南部もぐり観光RPG — 実装タスク一覧

初学者が上から順番に実装するためのタスクです。  
1タスクずつ進め、完了条件を満たしてから次へ進んでください。

参照ドキュメント：`docs/ai_context.md` / `docs/requirements.md` / `docs/screens.md` / `docs/routes.md` / `docs/database.md` / `docs/coding_rules.md`

管理画面、ログイン、メール登録、画像投稿、AI推薦、スクレイピングは対象外です。

## 進め方の注意

- 一度に複数タスクを同時実装しない
- 各タスクの完了条件を満たしてから次へ進む
- 不明な仕様は推測で埋めず、ドキュメントまたは関係者へ確認する
- コードを書く前に、対象タスク番号と完了条件を明示する
- 称号を候補からランダム選択する実装・タスクは作らない
- ランダム処理は豆絞り柄の候補選択にだけ使う
